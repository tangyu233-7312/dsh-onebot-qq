# 语音唱歌、PC 算力与解析侧车

本文按当前 custom 分支说明依赖与接入方式。仓库提供语音插件、视频解析侧车源码和 RVC 能力包脚本；PC 网关/Worker、音色模型及曲库需要自行准备。不要把“插件已加载”当作“功能已开启、后端已就绪”。

## 语音与唱歌的默认状态

| 配置 | 默认 | 含义 |
|---|---|---|
| `plugins.voice` | 未禁用 | 语音插件正常加载；可在「子插件」页单独停用 |
| `pluginConfig.voice.ttsEnabled` | false | 语音输出开关 |
| `pluginConfig.voice.singEnabled` | false | 唱歌开关，与语音输出独立 |
| `pluginConfig.voice.autoSpeak` | false | 是否自动朗读文字回复 |
| `pluginConfig.voice.autoLibrary` | true | 是否自动收集收到的音频到曲库 |

旧文档里的 `pluginConfig.voice.enabled` 总开关已从语音配置表移除。使用语音不需要同时打开唱歌，使用唱歌也不需要同时打开语音；工具是否注册与本轮能否执行不能混为一谈。

## 先选计算位置

| 方案 | 机器人所在机器 | 计算端 |
|---|---|---|
| **外部 PC 网关** | 配 `remoteUrl`、`remoteToken`；发送任务并接收音频 | 网关/Worker 负责 TTS、RVC、下载、silk 转码及相应依赖 |
| **本机计算** | 安装全部所需环境，并填写本机解释器、RVC 与音色路径 | 与机器人同机 |

NAS 借用 PC 算力时，不需要启动 PC QQ 机器人。当前远端成功路径可以把合成、按歌名下载/翻唱和 silk 转码都留在 PC；MiMo Key 由网关持有，机器人不会把本机 Key 传给远端。

**远端不可达、失败或超时会尝试本机回落**，不是自动保证成功。NAS 如果未准备本机依赖，就应预期回落可能失败；检查返回原因，不能将“已配置网关”等同于“网关必定可用”。

### 接 PC 算力网关

在「语音与唱歌」的 PC 算力网关分组填写地址与 token。网关是外部程序，本仓库没有一键部署脚本。下面是当前插件实际调用的接口，而不是任意网关通用标准：

| 接口 | 请求 / 返回约定 |
|---|---|
| `GET /health` | HTTP 成功表示网关可达；不能单独证明模型和 Worker 可用 |
| `POST /tts` | JSON：text、voice、instruct、backend；返回任务 `job`，或直接返回 base64 的 `wav` / `mp3` |
| `POST /sing-by-name` | JSON：query、pitch、model、proxy；返回任务 `job` |
| `GET /job/<id>` | 完成时返回 `ok:true, state:"done"` 及顶层 base64 `wav` / `mp3`；唱歌可附 `result.title` 等信息 |
| `POST /sing` | 本地已有音频时的兼容路径；multipart：file、pitch、可选 model；同步返回 base64 `audio` |
| `POST /to-silk` | 原始音频字节，Content-Type 为 application/octet-stream；同步返回 base64 `silk`，可附 seconds、bytes |

配置 token 时，这些请求使用 Bearer 鉴权。异步合成和按歌名翻唱需要轮询 `/job/<id>`，仅收到任务编号不算已生成音频。实现细节以 [语音插件](../plugins/voice/index.js) 的调用代码为准。

### 在机器人本机计算

当前 `speak` 链路是 **MiMo 内置 TTS → RVC 换音色 → 转码 → QQ 语音**；`sing` 是曲库或下载音频 → 人声分离 → RVC → 混回伴奏 → QQ 语音。

| 依赖 / 配置 | 用途 |
|---|---|
| TTS Python、pysilk、ffmpeg | 合成脚本与 silk 转码；填写 `ttsPython` |
| MiMo Key | 当前本机 TTS 使用；填写语音配置的 `apiKey` 或实例的 `credentials.mimoTts` |
| RVC Python、torch、RVC 能力包 | 说话和唱歌都使用；填写 `rvcPython`、`rvcDir` |
| `.pth` 音色，可选同名 `.index` | 放在 RVC 目录的 voice-models 中；可用 `singModel` 指定 |
| ffprobe、按需安装 yt-dlp | 本机点歌的时长检查、B 站下载 |

现有 RVC 依赖建议使用 Python 3.10；其他版本要先确认依赖兼容。当前插件按 CUDA 设备调用 RVC，不能仅凭能力包能安装 CPU 版就承诺整条机器人链路可用；无 GPU 场景优先考虑外部计算端。

`tts_say.py` 还支持 edge 等后端，但当前插件调用选择的是 `mimo-builtin`，控制台并没有通用的后端切换项。只安装 edge-tts，或只看旧脚本示例，并不能替代当前链路的 Key、RVC 与音色配置。

RVC 脚本在 [tools/singing-pack](../tools/singing-pack/)；先准备依赖并用其 info 命令检查，再配置插件。耗时、音高和相似度随模型、音频与硬件变化，旧实例的调参数字不能当作通用上限。

### 曲库

- 自动收集：`autoLibrary` 默认开，按大小限制下载收到的音频。
- 本机曲库：`musicDir` 默认是数据目录中的 music_mp3。
- 本机找不到时：`biliSearch` 控制是否去 B 站找；BV 号或 B 站链接也可作为点歌输入。
- 远端按歌名任务优先交给 PC，PC 的曲库与机器人本地曲库需要分别管理。

## 视频解析侧车

`sidecar/` 是独立 HTTP 服务，负责下载和抽帧；`sidecar-control` 是负责管理它的子插件，两者不是同一个东西。

| 使用者 | 默认 | 作用 |
|---|---|---|
| video-read | 开 | 读取 QQ 视频附件 |
| video-link-read | 开 | 读取 B 站链接和 BV 号 |
| video-wander | 开，定时自动看关 | 当前对话观看、后台观看和定时挑视频 |
| link-parser | 关 | 将链接媒体下载后发送到 QQ |
| sidecar-control.autoStart | 关 | 自动检查并拉起侧车 |

**默认不自动启动，不代表只能手动双击脚本。** 配好 sidecarDir 后，可在控制台启动，主人也可用 `/sidecar start`；开启 autoStart 后会自动检查并尝试拉起。若由 systemd、计划任务或容器管理，避免再开一套重复的进程管理。

侧车源码在 Git 仓库中，**当前 npm 包不含 sidecar 目录**。先单独部署源码与依赖，再将 sidecarDir 指向实际目录；默认相对实例数据目录解析。详细启动命令见 [侧车说明](../sidecar/README.md)。

依赖是 Node.js 22+、ffmpeg/ffprobe；下载 B 站媒体时还要 yt-dlp。使用独立 yt-dlp 可执行文件时，不必另装 Python 模块。当前抖音支持已下线，不能根据旧文档承诺可用。

侧车默认地址是 `http://127.0.0.1:3972`。它返回本地文件路径，因此通常与机器人同机或共享同一文件系统；跨机器部署需要另外解决返回路径的可读性，不能只替换 IP。

## 看视频的入口与配置

- `watch_now`：把抽帧结果交给当前这一轮的模型，由它在当前对话说明所见。
- `watch_video`：发起后台观看，完成后另行投递感想。
- 定时自动看：由 `autoEnabled` 单独控制；关闭定时不等于禁用对话里的观看工具。
- 观看通道、冷却、每日额度和静默时段以实例配置为准；默认值查各插件 configSchema。

视频附件与视频链接的参数在「文件与图片」，主动观看在「自己找视频看」。模型需要能处理图片；没有取得画面时应按实际失败原因说明，不能仅凭标题声称看过视频。

「多久看一次」按**分钟**填（`everyMinutes`，默认 240 = 4 小时），所以 20 分钟这种间隔也设得了。旧配置里的小时值（`everyHours`）在装配时自动折算，不会退回默认值，也不会改写实例配置文件。

抽帧分短视频/长视频两档，三处口径一致：「自己找视频看」是 `frames` / `framesLong` / `framesSplitMin`（分钟），「文件与图片」页的视频附件与 B 站链接是 `frames` / `framesLong` / `framesSplitSec`（秒）。分档由侧车按**实际时长**决定，超过阈值就用长视频帧数；`framesLong` 会被夹在侧车硬上限 24 帧内。

字幕开关集中在「文件与图片 → B站链接 · 读哪些内容」；登录态在「链接解析 → 看视频（侧车）」配置。详细步骤、状态字段与无字幕时的判断见 [侧车字幕说明](../sidecar/README.md#b-站字幕配置与排查)。

## 生图与这两套服务的关系

生图由 imagegen 配置自己的来源，可以通过 localUrl 直连 PC ComfyUI，也可以调用云端生图 API。它不依赖这里的语音网关或视频解析侧车。

更多功能见 [使用说明书](使用说明书.md)，当前配置及维护边界见 [维护与交接](维护与交接.md)。
