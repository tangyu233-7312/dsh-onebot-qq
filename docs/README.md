# QQ 机器人功能手册 · 总览与导航

> 这是 `dsh-onebot-qq` 管线的**唯一文档入口**。按「你现在要做什么」往下找；细节都在下面对应的手册里。
>
> **适用**：插件 v0.1.1 ｜ DSH `>= 0.2.1-rc.2 < 0.3.0` ｜ Node ≥ 22 ｜ Linux / Windows / macOS
>
> 一分钟看懂它是什么：

```text
QQ 客户端 ↔ 协议端（OneBot v11） ↔ 本插件（DSH 进程内：微内核 + 可插拔子插件） ↔ DSH（模型 / 会话 / 控制台）
```

安装后只有一处入口要记：**DSH 设置 →「QQ 控制台」**（每个子插件一页 + 若干核心页，改配置热生效）。

---

## 一、30 秒上手路线

```text
① 装插件         dsh plugin --profile web add github:YUsaltyfish/dsh-onebot-qq
② 建数据目录     node bin/dsh-onebot-qq.mjs init      （首次启动也会自动投递默认人设）
③ 启动           dsh web                              （首次缺配置会进「待配置模式」）
④ 连 QQ          控制台「新手向导」填主人 QQ + 协议端地址 → 自动连接
⑤ 试一句         QQ 里 @ 它 / 私聊发一句话 → 有回复即成功
```

- **Linux / macOS**：完整步骤看 [安装与卸载](安装与卸载.md)，日常功能看 [使用说明书](使用说明书.md)。
- **Windows**：一路看 [Windows 安装](Windows安装.md)（从装 Node 到真机验证），功能部分同样看 [使用说明书](使用说明书.md)。
- **只想让 AI 帮你装**：把 [安装与卸载](安装与卸载.md) 或 [Windows 安装](Windows安装.md) 整份丢给 DSH，让它照着做。

## 三、功能总览（一个能力一行）

> 每个子插件都能在控制台单独开关（控制台「子插件」页）；标「可选」的装了默认就生效、不装也不影响主流程（看视频类需要侧车，缺侧车自动降级）。

| 能力 | 一句话用法 | 控制台页 | 详解 |
|---|---|---|---|
| **唤醒与门禁** | 群里默认被叫才回（@ / 引用 / 唤醒词 / 接续窗口）；私聊永远回 | 唤醒、群聊 | [§5.1](使用说明书.md#51-叫醒它) |
| **收文件 / 发图** | 文件「被叫到才下载」（20MB / 5 个 / 留 7 天）；发图只认白名单目录 | 文件与图片、其他 | [§5.2](使用说明书.md#52-聊天--发图--长文) [§5.3](使用说明书.md#53-收文件) |
| **生图 / 图生图** | 直接说「画一只…」；改图就发图 / 引用图再说「改成…」 | 生图 | [§5.4](使用说明书.md#54-生图--图生图) |
| **群友头像** | 说「用他的头像画…」→ 自动取公开头像当参考图 | 其他（头像组） | [§5.5](使用说明书.md#55-头像) |
| **本机图片 / 参考图** | 说「用那张参考图 / 上次那张」→ 先调 `list_images` 列图，再挑一张当参考 | 生图 | [§5.4](使用说明书.md#54-生图--图生图) |
| **表情包** | 收表情可开关（默认只读不写索引）；回话时按概率提醒它顺手带一张 | 表情包 | [§5.6](使用说明书.md#56-表情包) |
| **入群欢迎** | 每组可勾；欢迎语用固定句池（零 token）或模型现写 | 入群欢迎 | [§5.7](使用说明书.md#57-入群欢迎) |
| **群记忆** | 每群一篇 Markdown；定时批量提炼要点（一轮一次调用），原始记录滚动保留 3 天 | 群记忆 | [§5.8](使用说明书.md#58-群记忆) |
| **链接解析**（可选） | B 站 / 抖音链接自动发媒体；需自备解析侧车 | 链接解析 | [§5.9](使用说明书.md#59-链接解析可选) |
| **主动接话**（可选） | 话题接话 + 冷场找话（**群聊与私聊**都支持）；群卡片与「主动接话」页两处都开才生效；另有静默时段 | 主动接话、群聊 | [§5.10](使用说明书.md#510-主动接话可选) |
| **权限 / 门禁** | 主人 QQ 决定脱敏豁免与命令权限；支持屏蔽群、黑白名单 | 群聊、其他 | [§5.11](使用说明书.md#511-权限与门禁) |
| **看视频**（可选） | 群视频 / 视频链接 / **裸 BV 号**抽帧给模型看；需本地解析侧车（ffmpeg） | 文件与图片 | [§5.12](使用说明书.md#512-看视频可选需要侧车) |
| **自己找视频看** | 隔几小时自己从 B 站挑一个视频看，写完感想把「标题 + 感想 + 链接」私聊发给主人；全部参数在它自己那一页 | 自己找视频看 | [配置参考 §五](配置参考.md#五子插件配置pluginconfigid) |
| **QQ 空间日记** | 每天最多一条说说，写不写它自己判断；定时回想一整天的事（空间工作区会话） | 空间日记 | [配置参考 §五](配置参考.md#五子插件配置pluginconfigid) |
| **斜杠命令** | `/help` 任何人；`/status` `/reset` `/resetall confirm` `/cancel` `/quota` `/history [N]` 仅主人 | — | [§5.11](使用说明书.md#511-权限与门禁) |
| **防刷屏**（可选） | 同一个人同一句话刷屏 → 冷却回一句，零 token | 唤醒 | [配置参考 §五](配置参考.md#五子插件配置pluginconfigid) |
| **私聊好友门禁**（可选） | 私聊只回好友（好友列表拉取失败时放行） | 其他 | [配置参考 §五](配置参考.md#五子插件配置pluginconfigid) |
| **聊天留档** | 文本/媒体进出都留档到 `logs/qq_chat/`（默认开） | 其他 | [配置参考](配置参考.md#archive) |
| **QQ 控制台** | 每个子插件一页 + 若干核心页；配置热改（原子写 + 备份 + 失败回滚） | 全部 | [§4](使用说明书.md#4-控制台一页一览) |
| **工具门**（可选插件） | 摘掉漏进 QQ 会话的全局工具（`ops_*` / agent-team / MCP） | — | [安装与卸载 §三](安装与卸载.md#可选qq-线工具门挡住全局工具) |
| **子插件扩展** | 新建 `plugins/<id>/index.js` 即自动发现，坏一个不影响其他 | 子插件 | [开发指南](开发指南.md) |

> 本机维护记录与补丁属于**部署机私有资料**，**不在本仓库**（不随插件发布 / 不进 npm 包）。

**文档纪律（防止再次散架）**

1. **一个主题只有一份**：功能写在「使用说明书」，安装写在「安装与卸载」，键写在「配置参考」；别的文档只放链接，不抄整段。
2. **改功能 → 同一次改动里改对应文档**；新增配置键 → 补「配置参考」；新增命令/工具 → 补「使用说明书」与「开发指南」。
3. 文档里只写**占位符**（`10001`、`~/...`、`https://example.invalid`），不写真实 QQ 号 / 群号 / token / 机器路径。
4. 历史文档（旧 standalone 时代的《QQ机器人功能手册》）**已作废**，不要按旧文里的旧桥接路径、旧进程名（`onebot-dsh-bridge`）操作。

**旧称对照**（读旧文档 / 维护记录时用）

| 旧称 | 现在 |
|---|---|
| 桥接 / bridge / standalone | 插件内核（`dsh-onebot-qq`，in-process；旧独立进程已废弃） |
| qq-lines 工作区 | `<dataDir>/workspace`（QQ 线工作区） |
| 回话模式页 | 控制台「主动接话」页（配置 `pacing.reply`） |
