## 维护文档

- 功能用法写在使用说明书，配置键写在配置参考，侧车协议与字幕排错写在侧车说明。导航只放链接，避免多处参数表长期漂移。
- 改功能时同步更新对应文档；默认值以当前代码 schema 为准，已有实例配置另行核对。
- 通用文档只用占位示例。站点地址、账号、登录态、会话、部署备份保留在部署机私有交接资料中。
- 旧 standalone / bridge 进程已经废弃。历史记录中的旧路径与状态不能直接作为当前操作指令。

发布前运行 `node scripts/check-doc-links.mjs`；它检查目标文件是否存在，不校验标题锚点或远端网站。
